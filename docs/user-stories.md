# User Stories

## Box Management

- As a user, I want to add a Pokemon by name with autocomplete and automatic form normalization so that I do not have to manually enter its stats.
- As a user, I want to see the Pokemon image, name, and types in my box so that I can scan the roster quickly in cards or table view.
- As a user, I want to inspect a Pokemon in detail so that I can evaluate its stats, abilities, moves, and defensive type multipliers.
- As a user, I want to sort my box by stats so that I can prioritize strong candidates for my teams.
- As a user, I want to filter my box by types, stat ranges, Mega capability, favorites, and custom tags.
- As a user, I want to mark favorite Pokemon and assign custom role tags (e.g. lead, sweeper, support) for fast organization.
- As a user, I want to save and restore filtered box views to reuse common analysis criteria.
- As a user, I want bulk actions (tag, favorite, delete with Undo) to manage multiple entries efficiently.
- As a user, I want to export visible or selected box data to CSV for external spreadsheet analysis.

## Team Building

- As a user, I want to add a Pokemon from my box to a team so that I can build squads without retyping data.
- As a user, I want to create, rename, switch, and delete multiple teams.
- As a user, I want to edit team members, items (with legality guardrails and stat deltas), and movesets (ranked by tournament usage).
- As a user, I want to configure Champions stat points (0–32 per stat, 66 budget, level 50) using sliders and presets (sweeper, bulky support, min speed).
- As a user, I want to import/export Showdown team pastes and publish directly to Pokepast.es.
- As a user, I want to add planned/template Pokémon to a team without cluttering my active box roster.
- As a user, I want to see offensive type coverage and defensive type matrices to identify team gaps.
- As a user, I want to compare teams side-by-side to evaluate stat averages, health checks, and shared weaknesses.

## Tournament Explorer & Meta Analytics

- As a user, I want to browse official (Worlds, Internationals, Regionals) and community VGC tournament standings and team sheets.
- As a user, I want to filter tournament teams by how many members are missing from my box (0, 1, 2, or 3 missing) to find rosters I can build immediately.
- As a user, I want to import winning tournament rosters directly into my active team builder with one click.
- As a user, I want to view teammate co-occurrence synergy percentages to identify proven partner combinations from real tournament data.

## Damage Calculator

- As a user, I want to calculate move damage roll-by-roll in both directions at once with KO chances and Smogon-style descriptions following Champions mechanics.
- As a user, I want to toggle field conditions (singles/doubles, weather, terrain, Tailwind, Trick Room, screens, hazards) with one click.
- As a user, I want to toggle status moves with known effects (boosts, weather, screens, status) directly on move cards.
- As a user, I want to sweep all Champions species against my attacker to classify them into Crushed, Threat, Wall, Mitigated, or Neutral matchups.
- As a user, I want to preview move damage directly inside the move picker and sort candidate moves by damage.
- As a user, I want to send team members, box entries, and tournament roster entries into the calculator with one click.

## Settings, Sync & Packaging

- As a user, I want to view and trigger background synchronizations for PokéAPI, Showdown catalogues, Limitless VGC, and Victory Road.
- As a user, I want to run the tool as a native desktop app, a web browser GUI, or an interactive terminal shell.
- As a user, I want to package standalone executables natively or cross-compile portable Windows `.exe` binaries from Linux.
