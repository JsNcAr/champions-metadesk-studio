# User Stories

## Box Management

- As a user, I want to add a Pokemon by name so that I do not have to manually enter its stats.
- As a user, I want to see the Pokemon image, name, and types in my box so that I can scan the roster quickly.
- As a user, I want to inspect a Pokemon in detail so that I can evaluate its stats, abilities, and moves.
- As a user, I want to sort my box by stats so that I can prioritize strong candidates for my teams.
- As a user, I want to filter my box by stat ranges and forms so that I can focus on Pokemon that meet a specific strategy.
- As a user, I want to choose which extra stats are visible so that I can adapt the box view to my planning needs.
- As a user, I want to export box data to CSV so that I can analyze it in a spreadsheet.
- As a user, I want to see defensive damage multipliers by attack type so that I can quickly understand weaknesses and resistances.

## Team Building

- As a user, I want to add a Pokemon from my box to a team so that I can build squads without retyping data.
- As a user, I want to create multiple teams so that I can plan different strategies.
- As a user, I want to edit team members, items, and movesets so that I can refine each build.
- As a user, I want to see my team's type coverage so that I can understand offensive gaps.
- As a user, I want to see my team's total stats so that I can compare power across teams.

## Suggested Additional Stories

- As a user, I want to mark favorite Pokemon so that I can find them quickly.
- As a user, I want to tag Pokemon by role so that I can filter for leads, sweepers, walls, and support picks.
- As a user, I want to save and restore filtered box views so that I can reuse common analysis setups.
- As a user, I want bulk import and bulk export options so that I can move data in and out efficiently.

## Acceptance Criteria Pattern

For each story, define:

- the primary action
- the expected data shown or saved
- success and failure states
- persistence behavior
- any validation rules
